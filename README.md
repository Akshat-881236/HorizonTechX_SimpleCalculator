## 📖 Overview

The **HorizonTechX Simple Calculator** is an elegantly designed web-based calculator that bridges the gap between aesthetic appeal and mathematical utility. Featuring a striking dark/light mode toggle, dynamic font-scaling, and enterprise-grade input handling, this application is designed to be as visually pleasing as it is reliable.

Whether you are using a desktop keyboard, a tablet, or a mobile device, the application intelligently adapts to your screen and input methods.

## ✨ Key Features

* **🌓 Adaptive Theming:** Seamlessly toggle between a neon-accented Dark Mode and a crisp Light Mode. Preferences are saved automatically via local storage.
* **📱 Universal Responsiveness:** Built with Bootstrap 5 and custom CSS grid, ensuring a flawless layout across 4K monitors, tablets, and small mobile screens.
* **⌨️ Full Keyboard Integration:** Navigate and calculate entirely via your keyboard. Includes custom shortcuts for clearing, copying, and theme toggling.
* **🔠 Enterprise Font Scaling:** Dynamic JavaScript observer that automatically shrinks the font size of the display as the output number grows, preventing UI breakage.
* **🧮 Scientific Notation Handling:** Intelligently converts numbers exceeding 16 digits into E-notation, keeping massive calculations clean and readable.
* **✨ Fluid Animations:** Features a customized particle background, subtle box-shadow pulses, and satisfying button-click scaling for an immersive UX.

## 🛠️ Technology Stack

* **Frontend:** HTML5, CSS3 (Custom Variables, Animations, Flexbox/Grid)
* **Logic:** Vanilla JavaScript (ES6 Classes, MutationObservers, Event Delegation)
* **Frameworks/Libraries:** Bootstrap 5 (CDN) for structural scaffolding.
* **Typography:** Google Fonts (`Inter` for UI, `Orbitron` for digital display).

## 📖 User Manual & Shortcuts

The HorizonTechX Calculator is designed for power users. While fully functional via mouse or touch, it truly shines when used with a keyboard.

### 🖱️ On-Screen Interface
* **`C` Button:** Clears the current expression and memory.
* **`⌫` Button:** Deletes the last entered character.
* **`🌙/☀️` Button:** Toggles the application theme.

### ⌨️ Keyboard Shortcuts
To maximize your productivity, use the following key bindings:

| Key / Combination | Action Performed |
| :--- | :--- |
| `0` - `9` | Input numbers |
| `+`, `-`, `*`, `/`, `%` | Mathematical operators |
| `.` | Add decimal point |
| `Enter` | Calculate result (Equals) |
| `Backspace` | Delete the last character |
| `Escape` | Clear the display (Soft Reset) |
| `F10` | Full Clear |
| `F2` | Toggle Dark/Light Theme |
| `Ctrl + C` | Copy the current displayed number to clipboard |
| `Ctrl + L` | Clear the display |

## 🚀 Installation & Local Setup

Because this project is built with plain HTML, CSS, and JavaScript, no complex build tools or package managers are required.

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/akshat-881236/HorizonTechX_SimpleCalculator.git](https://github.com/akshat-881236/HorizonTechX_SimpleCalculator.git)
   ```

2. **Navigate to the directory:**
```bash
cd HorizonTechX_SimpleCalculator
```


3. **Run the app:**
Simply open the `index.html` file in your preferred web browser, or use an extension like VS Code's "Live Server" for hot reloading during development.
